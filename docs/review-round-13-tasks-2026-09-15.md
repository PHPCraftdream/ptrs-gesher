Агенты hl работают в отдельных worktree; владелец проверяет результат,
переносит одну задачу, коммитит и сразу отправляет её в origin/main.

| Задача | P | Состояние | Приёмка |
|---|---|---|---|
| PT13-01 | P2 | Запланирована | IAT управляет carrier writes и flush; partial/error/shutdown не ломаются |
| PT13-02 | P2 | Запланирована первой среди statefile-задач | Числовой Go iat-mode и старые строковые файлы совместимы |
| PT13-03 | P2 | После PT13-02 | Builder объявляет effective identity построенного сервера |
| PT13-04 | P2 | После PT13-03 | Override ключевой пары сохраняет node ID из statefile |
| PT13-05 | P2 | Запланирована | Новый фильтр действует внутри ранее созданных spans |
| PT13-06 | P3 | Запланирована | Учёт abort handles без O(C) прохода на каждый admission |

нагрузки не запускаются. Прежний автоматический цикл новых ревью этим
поручением не возобновляется: объём — перечисленные шесть задач.
