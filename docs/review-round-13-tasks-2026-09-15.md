# Исправление раунда 13

Требования: [ревью](review-round-13-2026-09-15.md).
Агенты hl работают в отдельных worktree; владелец проверяет результат,
переносит одну задачу, коммитит и сразу отправляет её в origin/main.

| PT13-06 | P3 | Запланирована | Учёт abort handles без O(C) прохода на каждый admission |

Версии, release tags и публикация не меняются. Benchmarks и искусственные
нагрузки не запускаются. Прежний автоматический цикл новых ревью этим
поручением не возобновляется: объём — перечисленные шесть задач.

PT13-02: каноническая JSON-запись — число 0/1/2; legacy строки читаются,
неподходящие типы и значения отклоняются. Импорт server state клиентом
сохраняет исходный файл. Первая сборка завершилась ошибкой выделения памяти;
последовательный повтор с `-j1` и полный набор тестов прошли. Новые зависимости
и изменения версий не потребовались.

PT13-01: Enabled ограничивает carrier-порции MTU; Paranoid выбирает длину
порции и добавляет зашифрованный padding через codec. Частичные записи
продолжают ту же порцию; задержка применяется после её завершения, flush
проходит через тот же планировщик. Shutdown сохраняет прежнюю отмену задержек.
Два отрицательных контроля отдельно обнаружили отключение задержки и подмену
Paranoid-размера на MTU; контрольные мутации удалены. Clippy/fmt прошли.
Rust interop example собран отдельно с `-j1`; runner использовал этот binary
и проверил оба направления и malformed reply. Это не benchmark.
